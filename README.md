# 🏠 Airbnb Data Analysis

## 📌 Overview
An in-depth analysis of a 100,000-record Airbnb dataset using SQL and Python, uncovering pricing trends, property type distributions, review score patterns, and availability across multiple cities — providing actionable insights for both hosts and guests.

## 🎯 Objectives
- Analyze pricing trends across cities and property types
- Identify top cities by average nightly price
- Examine review score distributions for high-volume listings
- Analyze room type distribution across price ranges
- Profile top hosts by listing count and ratings

---

## 📊 Dataset Description

| Column | Description |
|---|---|
| Listing ID | Unique identifier for each listing |
| Host ID | Unique identifier for each host |
| City | City where the property is located |
| Property Type | Apartment, House, Villa, Condo etc. |
| Room Type | Entire Home, Private Room, Shared Room |
| Price | Price per night in USD |
| Minimum Nights | Minimum booking duration |
| Number of Reviews | Total guest reviews |
| Review Scores Rating | Average rating score |
| Availability | Available days in next 365 days |

---

## 🔑 Key Insights
- Identified top cities with highest average nightly prices
- Most common property types vary significantly across cities
- Properties with 100+ reviews show distinct rating patterns
- Room type distribution differs across budget vs premium price ranges
- Top hosts by listing count analyzed for review score performance
